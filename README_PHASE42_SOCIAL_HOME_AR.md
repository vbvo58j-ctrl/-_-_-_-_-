# المرحلة 42 — الصفحة الاجتماعية الموحّدة

## التغيير المنفذ
- إضافة `lib/screens/social_home_screen.dart` كصفحة هبوط اجتماعية تجمع شريط القصص أعلى خلاصة المنشورات.
- ربط الصفحة في `IndexedStack` داخل `main.dart` بدلاً من عرض خلاصة المنشورات وحدها في التبويب الثاني.
- إعادة استخدام `StoriesStrip` و`PublicFeedScreen` كما هما؛ لم يتم نسخ منطق الوسائط أو التخزين أو المزامنة.
- لم تتغير مفاتيح SharedPreferences أو صيغ بيانات القصص والمنشورات أو قنوات النقل.

## سلوك الواجهة
- تظهر القصص أفقياً أعلى الصفحة، مع زر إنشاء القصة الموجود مسبقاً.
- تظهر المنشورات في الجزء القابل للتمرير أسفل القصص، وتظل أدوات الإنشاء والتحديث والتفاعل ضمن شاشة الخلاصة الحالية.
- تبويب القصص المنفصل الحالي لم يُحذف حفاظاً على مسار الاستخدام السابق.

## حدود التحقق
- فحص ساكن للتغييرات فقط.
- لم يُشغّل `flutter analyze` أو بناء Android لعدم توفر Flutter/Android SDK في بيئة التنفيذ.
- يلزم اختبار الواجهة على جهاز فعلي للتأكد من قياسات العرض وسلوك التمرير مع لوحة المفاتيح والاتجاه RTL.
