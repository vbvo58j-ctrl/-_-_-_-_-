# المرحلة 34 — فصل حالة الخدمة عن واجهة التطبيق

- إضافة `runtimeSnapshot()` لإعادة لقطة وصفية عند إعادة ربط Flutter بالخدمة.
- اللقطة تعرض حالة Wi-Fi Aware وعدد الجلسات ومعرّف حقبة الخدمة والأحداث المعلقة فقط.
- لا تُعاد مفاتيح أو كلمات مرور أو أجسام رسائل إلى الواجهة.
- إضافة `serviceEpoch` لتمييز عمر نسخة الخدمة عن عمر Activity.

التحقق: مراجعة ساكنة فقط؛ يلزم اختبار إعادة إنشاء Activity على جهاز Android فعلي.
