# المرحلة 43 — فصل واجهة الملف الشخصي

## ما تم تغييره
- إنشاء `lib/screens/profile_screen.dart` لنقل عرض الملف الشخصي إلى شاشة مستقلة.
- تمرير اسم المستخدم ومسار الصورة ودالة فتح الإعدادات عبر معاملات واضحة.
- تعديل `lib/main.dart` لاستخدام `ProfileScreen` بدلاً من بناء الواجهة داخل حالة التطبيق الرئيسية.
- إبقاء حفظ الإعدادات وتغيير الاسم/الصورة وتشغيل خدمات الاتصال داخل `BlousabShell`؛ لم يتم نقل منطق الخدمات أو التخزين إلى الشاشة الجديدة.

## حدود التغيير
- زرا «الإعدادات» و«تعديل الملف الشخصي» ما زالا يفتحان تدفق الإعدادات نفسه كما في السابق.
- لم يتغير ترتيب التبويبات أو تسمياتها أو منطق الاتصال والتشفير أو مزامنة القصص والمنشورات.

## التحقق
- تمت مراجعة التعديل نصياً والتأكد من وجود الاستيراد واستدعاء الشاشة الجديدة.
- لم يتم تشغيل `flutter analyze` أو بناء APK أو اختبار واجهة على جهاز؛ أدوات Flutter/Android غير متاحة في بيئة العمل الحالية.
- يلزم اختبار عرض صورة الملف عند وجودها وعند غيابها، والتنقل إلى الإعدادات والعودة، على جهاز Android فعلي.
