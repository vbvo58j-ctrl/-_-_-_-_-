# المرحلة 41 — حدود طبقة الواجهات الاجتماعية

هذه مرحلة تنظيمية لا تغيّر سلوك المنشورات أو التخزين. قبل استخراج الشاشات إلى وحدات مستقلة، يجب الحفاظ على العقود الحالية التالية:

- `public_feed_screen.dart`: عرض المنشورات والتفاعلات ومزامنتها مع `community_store.dart`.
- `stories_strip.dart`: عرض القصص مع الحفاظ على سلوك الوسائط والانتهاء.
- `communities_screen.dart`: المجتمعات والعضوية.
- إعدادات الهوية والثقة تبقى منفصلة عن إعدادات المظهر والإشعارات.

## ترتيب التنفيذ المقترح
1. استخراج شاشة الإعدادات إلى `lib/screens/settings_screen.dart` مع إبقاء مفاتيح التخزين الحالية دون إعادة تسمية.
2. فصل أقسام الخصوصية والإشعارات والمظهر إلى Widgets صغيرة دون نقل منطق التخزين في الخطوة نفسها.
3. توحيد تنقل المنشورات والقصص والملف الشخصي بعد إضافة اختبارات انحدار للتفاعلات والمزامنة.

## معيار القبول
لا تُحذف أي شاشة أو مفتاح تفضيل قائم، ولا يتغير تنسيق البيانات المحلية، ويجب اجتياز `flutter analyze` واختبارات الواجهة قبل اعتماد النقل. هذه الوثيقة خطة تنفيذ وليست ادعاءً بأن إعادة الهيكلة قد تمت.
