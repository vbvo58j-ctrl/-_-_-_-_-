# المرحلة 37 — اختبارات عدم التراجع للتشفير

أُضيفت اختبارات JUnit لمخزن تشفير Wi-Fi Aware:
1. تبادل رسالة مشفرة في الاتجاهين مع عدادات متتابعة.
2. رفض إعادة تشغيل إطار سبق استلامه.
3. رفض العبث ببيانات AES-GCM مع التأكد من عدم استهلاك عداد الاستقبال عند فشل المصادقة.
4. رفض استبدال مفتاح جلسة دون إزالة صريحة أولاً.

التشغيل: `cd android && ./gradlew :app:testDebugUnitTest`

لم يتم تشغيل Gradle في هذه البيئة؛ الاختبارات مكتوبة لكنها غير منفذة هنا. يلزم كذلك اختبار هاتفين وبناء APK قبل اعتماد المراحل إنتاجياً.
