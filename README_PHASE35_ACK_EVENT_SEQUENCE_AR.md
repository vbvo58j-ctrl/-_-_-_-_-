# المرحلة 35 — تحسين تسليم الأحداث وإقرارها

- جعل معرّف الحدث متزايداً ويُحفظ في SharedPreferences قبل تسليم الحدث.
- لا تحفظ SharedPreferences أجسام الأحداث أو نصوص الرسائل؛ تحفظ الرقم فقط.
- تبقى الأحداث غير المؤكدة في الذاكرة وتُعاد عند إعادة ربط المستهلك، مع دلالة at-least-once.
- يجب على Flutter استدعاء `acknowledgeSessionEvent(eventId)` بعد تمرير الحدث إلى المستمعين.

مهم: طابور محتوى الأحداث لا يزال محدوداً بالذاكرة إلى 200 حدث؛ لا ندّعي استعادة محتوى حدث بعد قتل عملية Android.
