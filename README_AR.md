- `MainActivity.onDestroy()` ما زالت توقف Wi-Fi Aware؛ استمرار الجلسة بعد تدمير Activity غير منجز.
- لم يتم بناء APK أو تشغيل `flutter analyze` أو Gradle أو اختبارات JUnit أو اختبار هاتفين في هذه البيئة.
- لا يوجد محرك مكالمات صوتية/فيديو فعلي جاهز.
- راجع `README_PHASE38_INTEGRATION_AND_UI_PLAN_AR.md` للحدود ومعايير إغلاق الاتصال وخطة UI.

لا تعتبر هذه النسخة إصداراً إنتاجياً قبل اجتياز اختبارات البناء والأجهزة المذكورة.
