# المرحلة 36 — تشخيص حالة الشبكة والخدمة

- إضافة `runtimeHealth()` لإظهار حالة Wi-Fi Aware، وعدد جلسات TCP، وعدد أقران Bluetooth، وحالة المستمع.
- إضافة `runtimeSnapshot()` لعرض الأجهزة المتصلة ومعرّف حقبة الخدمة وعدد الأحداث المعلقة.
- لا تتضمن واجهات التشخيص عناوين MAC أو مفاتيح أو كلمات مرور أو محتوى رسائل.

يمكن ربط هذه الواجهات لاحقاً بصفحة مراقبة الشبكة في Flutter. لم تتم إضافة شاشة UI في هذه المرحلة.
